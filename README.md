### What I Build

Flutter developer at [TenTwenty](https://www.tentwenty.me/) building production cross-platform mobile apps for iOS and Android using Dart. Experienced with clean architecture, MVVM, BLoC, Riverpod, and Provider for state management. Day-to-day work spans custom Flutter widgets, animations, platform channels, deep linking, push notifications, Firebase (Auth, Firestore, Cloud Functions, Crashlytics), REST API integration, and app store deployment on both Google Play and the Apple App Store.

Also comfortable with React Native and Swift for native iOS work. Currently expanding into backend with **FastAPI + Python** to ship full-stack mobile products end to end.

Always happy to talk Flutter architecture, Dart, mobile performance, or anything cross-platform.
